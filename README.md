## 🌟 What is LinkedIn Tycoon?

LinkedIn Tycoon is a **pixel-art career simulation RPG** where you climb the corporate ladder through strategic networking, content creation, and skill development. Experience the thrill of professional growth in a vibrant 2D world inspired by real LinkedIn mechanics!

### ✨ Why Play?

- 🎨 **Gorgeous Pixel Art** - Retro-style graphics with modern gameplay
- 🌍 **Massive Open World** - Explore 15+ unique locations (Gym, Library, Coworking Space, Coffee Shops, and more!)
- 📈 **Deep Progression** - 50+ levels, 15+ skills, 30+ achievements
- 💼 **Career Simulation** - From Junior Engineer to Tech Industry Leader
- 🎵 **Dynamic Soundtrack** - Original music for every scene
- 💾 **Auto-Save** - Never lose your progress

## 🚀 Quick Start

### 🌐 Play Online (Recommended)
**Just click and play - no installation needed!**

👉 **[Launch Game](https://sammytourani.github.io/Linkedin-Tycoon/)** 👈

### 💻 Run Locally

```bash
# Clone the repository
git clone https://github.com/SammyTourani/Linkedin-Tycoon.git

# Navigate to directory
cd Linkedin-Tycoon

# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:3003 in your browser
```

## 🎮 How to Play

### 🎯 Basic Controls

| Key | Action |
|-----|--------|
| **WASD** / **Arrow Keys** | Move character |
| **Q** | Skip dialogue |
| **ESC** | Close menus |
| **F** | Toggle fullscreen |
| **E** | Interact with objects/NPCs |
| **I** | Open inventory |
| **P** | Open phone/menu |
| **M** | Toggle minimap |

### 📖 Getting Started

1. **Create Your Character**
   - Enter your name
   - Customize appearance (skin, hair, clothes)
   - Choose starting stats

2. **Complete Tutorial**
   - Learn basic controls
   - Understand core mechanics
   - Receive starter bonuses

3. **Explore the World**
   - Visit different locations
   - Talk to NPCs
   - Complete quests

4. **Build Your Career**
   - Network at events
   - Upgrade skills
   - Apply for jobs
   - Create content

5. **Progress & Unlock**
   - Level up through XP
   - Unlock new areas
   - Gain achievements
   - Prestige for bonuses

## 💎 Pro Tips & Strategies

<details>

### Energy Management
- 🔋 Energy regenerates 1 point per 10 seconds
- 🛏️ Rest at home for faster regeneration
- ☕ Coffee shops give temporary energy boosts
- 🏋️ Gym increases max energy over time

### Networking Success
- 👔 Upgrade your appearance for better first impressions
- 💼 Attend coworking space for high-value connections
- 🎤 Conference rooms offer the best networking ROI
- 📧 Check email daily for opportunities

### Career Advancement
- 📚 Balance technical AND soft skills
- 🎓 University courses provide the fastest skill gains
- 💻 Coworking projects give great XP
- 🏆 Complete achievements for permanent bonuses

### Money Making
- 💰 Early game: Focus on email responses and small projects
- 💼 Mid game: Take job interviews and hackathons
- 🚀 Late game: High-level positions provide passive income
- 🛍️ Don't overspend on cosmetics early

- ⏰ Plan your route to minimize travel time
- 🎯 Stack activities in the same area
- 📱 Use phone menu for quick navigation
- 🔄 Prestige when progression slows down

## 🚀 Deployment (GitHub Pages)

### Automatic Deployment

This repo is configured for **GitHub Pages**. Every push to `main` automatically deploys!

### Manual Setup

1. **Build the project:**
```bash
npm run build
```

2. **Deploy to GitHub Pages:**
```bash
# The build creates a 'dist' folder
# Push this to the gh-pages branch

git subtree push --prefix dist origin gh-pages
```

3. **Configure GitHub Pages:**
   - Go to repo **Settings** → **Pages**
   - Set source to `gh-pages` branch
   - Your game will be live at: `https://yourusername.github.io/Linkedin-Tycoon/`
