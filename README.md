## 🌟 Build Your Professional Empire

**LinkedIn Tycoon** is a pixel-art RPG where networking meets adventure. Start as a Junior Engineer, master the art of the interview, build your network, and climb the corporate ladder to become a Tech Industry Leader.

<br />

### 🌳 Find Your Balance
Burnout is real! Take a break at the **City Park** to recharge your energy and health. A balanced life is key to long-term success.

![City Park](Gifs/City%20Park.gif)

<br />

### 💼 Ace the Interview
Your career is in your hands. Navigate dynamic job interviews, negotiate your salary, and land prestigious roles at top tech companies.

![Interview](Gifs/Interview.gif)

<br />

### 📈 Climb the Ranks
Compete with other players! Network with NPCs, send messages, and build your reputation to reach the #1 spot on the global leaderboard.

![Leaderboard](Gifs/LeaderBoard%20&%20Messages.gif)

## 🚀 Quick Start

### Play Online
👉 **[Click here to play instantly](https://sammytourani.github.io/Linkedin-Tycoon/)**

### Run Locally
Want to mod the game or run it offline?

```bash
# 1. Clone the repo
git clone https://github.com/SammyTourani/Linkedin-Tycoon.git

# 2. Install dependencies
cd Linkedin-Tycoon
npm install

# 3. Start the game
npm run dev
```
